## How to Actually Use a Macy's Promo Code (And Why It Sometimes Doesn't Work)

Using the code itself is straightforward — add items to your bag, go to checkout, enter the promo code in the designated field before paying, hit Apply, and verify the discount shows up in your order summary. Simple.

But codes failing is common enough that it's worth knowing why:

**The most frequent culprits:**

1. **You're not logged in.** Some codes are unique to your email address and won't register without an active login.
2. **Excluded items in your cart.** Gift cards, certain designer brands (Marc Jacobs, Birkenstock, Hugo Boss, Mango), Apple products, and items from Shoes by Finish Line won't accept most promo codes. Remove them or check them out separately.
3. **Minimum spend isn't met.** Always read the fine print on whether the minimum applies before or after discounts.
4. **The code doesn't work on sale items.** A few Macy's codes are regular-price only. Others (like the 25% email sign-up code) explicitly work on sale and clearance too.
5. **You already used a conflicting promotion.** Macy's only allows one promo code per transaction. If you've got a deal applied via the Star Rewards system or a sale event, some codes won't layer on top.

One practical tip: if a code isn't working and you can't figure out why, try clearing your cart, starting fresh, and re-entering the code before adding items back. Sometimes the browser session carries over conflicting promotions.
